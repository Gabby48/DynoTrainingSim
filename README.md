This repository will store all projects for Dyno Training Sim, which aims to create a simulated dyno rolling road. This is for the purpose of training people to operate the dyno.
Problem Statement: How do you safely train individuals to operate the dyno whilst getting experience to be competent.
Solution: Training that isolates users who are not as experienced and gives them a level of competence and experience in a separate and safer environment than running the actual rig.

Features
-Simulating Start and Stop of the dyno, mimicking indicators and powering up of the Auxiliary and Full Dyno System. When stopping above a certain speed "vehicle" will slow down.
-Allow for all the regular rig modes = Speed, RLS (Road Load Sim), and Force.
-Simulate a driver driving at a specific rate in Light Drive and WOT Modes.
-Display a vehicle responding to changes like it would in the real rig.
-Display calculated Speed, Forces and Power from the rig to give the user an idea of the typical readings and make conclusions fromn this.

How to Run: 
-Dyno Sim will be a PC application that should be a simple double-click of a desktop icon.
-This will load into the full dyno screen on which users can operate the sim as designed.
-User can select start which will get dyno running and select modes as required.
-Prompts and indicators will allow user to identify the current rig state in order to see how to respond.


Tech Stack - Unreal Engine 5.8.3, Blueprints, GitUhb

Future Improvements: These will be determined upon testing.
